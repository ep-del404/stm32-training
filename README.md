# STM32 电控培训作业（第一阶段）

本仓库用于存放电控组第一阶段培训的作业代码。

## 环境

- 开发板：STM32F103C8T6 最小系统板
- 配置工具：STM32CubeMX 6.18.1
- 编译/烧录：Keil MDK 5.43a + ST-Link V2
- 版本管理：Git

## 作业清单

### 基础部分（必做）

- [ ] 1. 外接 LED 以 500ms 周期闪烁（使用 `HAL_Delay`）
- [ ] 2. 外接 LED 以 500ms 周期闪烁（不使用 `HAL_Delay`）
- [ ] 3. 按键通过 EXTI 中断控制 LED 开关，含 20ms 软件消抖
- [x] 4. 注册 GitHub 并把代码提交到本仓库

### 进阶部分（选做）

- [ ] 5. 短按（<1s）切换常亮/常灭；长按（>=1s）松手后 5Hz 快闪，再次长按退出
- [ ] 6. 双击（间隔 <500ms）翻转 LED，单击不动作

## 目录

| 目录 | 内容 |
| --- | --- |
| `01_blink_delay/` | 作业 1：HAL_Delay 闪烁 |
| `02_blink_timer/` | 作业 2：非阻塞闪烁（SysTick / 定时器） |
| `03_exti_key/` | 作业 3：EXTI 按键 + 20ms 消抖 |
| `04_advanced/` | 进阶 5、6：按键状态机 |

> 目录按实际进度创建，未完成的先留空。

## 说明

每个作业是独立的 Keil 工程（`.uvprojx`），可直接用 Keil 打开、编译、烧录。
提交记录对应各次完成情况，README 的勾选项会随进度更新。
